# The impact of the two-child benefit cap on parental health in the UK: a triangulation of policy evaluation methods

This repository contains the code for my PhD study on the impact of the UK two-child benefit cap on various aspects of parental health, which is now available on MedRxiv as a preprint [here](https://www.medrxiv.org/content/10.64898/2026.03.30.26349774v2).

The HTML Quarto version of the R script used for the most recent version can be found [here](https://anabellepauli.github.io/twochildbenefitcap/PhD-study-3-code-v2.html), with the initial v1 version being [here](https://anabellepauli.github.io/twochildbenefitcap/PhD%20study%203%20code.html).
