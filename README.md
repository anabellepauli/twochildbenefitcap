# The impact of the two-child benefit cap on parental mental, general, and financial health

This is the code for my PhD study on the impact of the UK two-child benefit cap on various aspects of parental health. I am uploading the Quarto document version of the R script used for the first version of the manuscript, which is now available on MedRxiv as a preprint: https://doi.org/10.64898/2026.03.30.26349774
