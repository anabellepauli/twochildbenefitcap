# The impact of the two-child benefit cap on parental mental, general, and financial health

This repository contains the code for my PhD study on the impact of the UK two-child benefit cap on various aspects of parental health, which is now available on MedRxiv as a preprint [here](https://doi.org/10.64898/2026.03.30.26349774).

The HTML Quarto version of the R script used for the initial preprint version can be found [here](https://anabellepauli.github.io/twochildbenefitcap/PhD%20study%203%20code.html).
